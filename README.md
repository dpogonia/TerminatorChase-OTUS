# Terminator Chase

Погоня T-1000 за T-800. Учебный проект OTUS, в этой копии строки на русском и английском.

## Что умеет приложение

На экране скорость, дистанция и повреждения обеих машин. Можно стартовать, поставить паузу, остановить игру и выстрелить. Если T-1000 догоняет, партия проиграна. Если T-800 уходит, партия выиграна.

Строки лежат в `ru.lproj` и `en.lproj`.

## Курс

Образец игры с занятия OTUS. Локализация в этой копии на двух языках.

## Стек

SwiftUI.

## Запуск

```bash
git clone https://github.com/dpogonia/TerminatorChase-OTUS.git
cd TerminatorChase-OTUS
open TEscape.xcodeproj
```

Запустите схему **TEscape** на симуляторе iPhone и смените язык системы, чтобы увидеть второй перевод.
