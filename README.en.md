# Terminator Chase

T-1000 chasing a T-800. An OTUS study project. This copy has Russian and English strings.

## What it does

The screen shows speed, distance, and damage for both machines. You can start, pause, stop, and shoot. If the T-1000 catches up, the round is lost. If the T-800 gets away, the round is won.

The strings live in `ru.lproj` and `en.lproj`.

## Course

A game sample from an OTUS lesson. This copy is localized in two languages.

## Stack

SwiftUI.

## Run

```bash
git clone https://github.com/dpogonia/TerminatorChase-OTUS.git
cd TerminatorChase-OTUS
open TEscape.xcodeproj
```

Run the **TEscape** scheme on an iPhone simulator and switch the system language to see the other translation.
